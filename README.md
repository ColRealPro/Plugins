# Plugins
Generated by [Rojo](https://github.com/rojo-rbx/rojo) 7.6.1.

## Getting Started
To build the place from scratch, use:

```bash
rojo build -o "Plugins.rbxlx"
```

Next, open `Plugins.rbxlx` in Roblox Studio and start the Rojo server:

```bash
rojo serve
```

For more help, check out [the Rojo documentation](https://rojo.space/docs).

## Running Tests

Install packages once:

```bash
wally install
```

Serve the test project to Studio:

```bash
rojo serve test.project.json
```

Then run this in Studio's command bar, or through the Studio MCP. The clone keeps repeated test runs from reusing Studio's cached `require` result while you edit specs:

```lua
local ReplicatedStorage = game:GetService("ReplicatedStorage")
local TestService = game:GetService("TestService")
local runner = ReplicatedStorage.tests.RunTests:Clone()
runner.Parent = TestService
local runTests = require(runner)
local results = runTests()
runner:Destroy()
return results
```

You can also build the test place:

```bash
rojo build test.project.json -o PluginsTests.rbxlx
```

Typecheck with Roblox definitions and the Rojo sourcemap:

```powershell
Invoke-WebRequest https://luau-lsp.pages.dev/type-definitions/globalTypes.PluginSecurity.d.luau -OutFile "$env:TEMP\globalTypes.PluginSecurity.d.luau"
rojo sourcemap test.project.json --output sourcemap.json
luau-lsp analyze --flag:LuauSolverV2=true --definitions=@roblox="$env:TEMP\globalTypes.PluginSecurity.d.luau" --sourcemap=sourcemap.json --ignore Packages/** .
```
